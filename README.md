# Amazon Clone Frontend

<img src="./amazon%20clone.png" alt="Amazon Clone Website" width="100%">
 ## 📌 About the Project

This project is a frontend clone of the Amazon website. It is an e-commerce website created using HTML and CSS to practice frontend web development and user interface design.
 ## ✨ Features

- Amazon-style homepage
- Navigation bar
- Search bar
- Product sections
- Product cards
- Shopping cart UI
- Attractive user interface
- Responsive layout
 ## 🛠️ Technologies Used

- HTML5
- CSS3
 ## 📂 Project Structure

Amazon-Clone/
│
├── index.html
├── style.css
├── images/
└── README.md
 ## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. The Amazon Clone website will open.
